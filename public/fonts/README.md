# فونت سازمانی — یکان بخ (YekanBakh)

فایل‌های `woff2` را با همین نام‌ها در همین پوشه قرار دهید:

| فایل                              | وزن css |
|-----------------------------------|---------|
| `YekanBakhFaNum-Thin.woff2`       | 100     |
| `YekanBakhFaNum-Light.woff2`      | 300     |
| `YekanBakhFaNum-Regular.woff2`    | 400     |
| `YekanBakhFaNum-SemiBold.woff2`   | 600     |
| `YekanBakhFaNum-Bold.woff2`       | 700     |
| `YekanBakhFaNum-ExtraBold.woff2`  | 800     |
| `YekanBakhFaNum-Black.woff2`      | 900     |
| `YekanBakhFaNum-ExtraBlack.woff2` | 950     |

نکته‌ها:
- تنظیمات `@font-face` در `styles.css` از قبل با همین نام‌ها آماده است؛ فقط کافی است فایل‌ها را
  اینجا کپی کنید — بدون هیچ تغییری در کد.
- تا وقتی فایل‌ها موجود نباشند، صفحه به‌صورت خودکار از **Vazirmatn** (گوگل‌فونت) استفاده می‌کند.
- نسخه FaNum اعداد را به‌صورت فارسی نمایش می‌دهد.
- استفاده‌ی فعلی صفحه: متن ۴۰۰ · تیترهای h2/h3 و دکمه‌ها ۷۰۰ · تیتر اصلی h1 با ۸۰۰.
