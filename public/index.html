Docker Registry API v2

رجیستری اختصاصی صدهانت — کامل، سریع و همیشه در دسترس

مرجع کامل ایمیج‌های داکر برای زیرساخت شما؛ هر ایمیج از هر رجیستری عمومی — برای عبور از محدودیت رجیستری‌های خارجی، بدون واسطه و بدون دردسر. فایل ایمیج بدون ذخیره‌سازی و پردازش اضافه، مستقیماً به کلاینت استریم می‌شود و با یک دستور docker load بارگذاری می‌شود.

نحوه کار

هر docker pull این مسیر را طی می‌کند. برای دیدن حرکت درخواست، دکمه شبیه‌سازی را بزنید.

  1. ۱

    درخواست دانلود

    GET /image?name=nginx:latest — با wget یا curl؛ خروجی مستقیماً به docker load pipe می‌شود یا با wget -c ذخیره و ادامه‌پذیر است.

  2. ۲

    انتخاب رجیستری

    رجیستری‌های پیکربندی‌شده به‌ترتیب از طریق سرویس منبع امتحان می‌شوند — اولین پاسخ موفق برنده است و بقیه اصلاً شروع نمی‌شوند.

  3. ۳

    استریم مستقیم به کلاینت

    تاربال ایمیج بدون هیچ ذخیره‌سازی و پردازشی، همان‌جا به کلاینت استریم می‌شود — بدون کش، بدون blob و بدون تبدیل. مصرف منابع تقریباً صفر است.

هیچ داده‌ای روی سرور نگه داشته نمی‌شود؛ دانلودهای نیمه‌تمام با wget -c از همان‌جایی که قطع شده ادامه می‌یابند.

امکانات

هر چیزی که از یک رجیستری اختصاصی کامل انتظار دارید.

  • پروتکل ساده HTTP

    دانلود با wget یا curl و بارگذاری با docker load؛ بدون هیچ تنظیمی روی کلاینت داکر.

  • استریم مستقیم

    هیچ ذخیره‌سازی و پردازشی روی سرور انجام نمی‌شود؛ تاربال ایمیج مستقیماً از منبع به کلاینت پاس می‌شود و مصرف منابع تقریباً صفر است.

  • fallback روی چند رجیستری

    ۱۳ منبع بالادستی — docker.io ،ghcr.io ،quay.io ،gcr.io ،mcr.microsoft.com، آروان‌کلود و… — به‌ترتیب امتحان می‌شوند؛ اولین موفق برنده است.

  • پشتیبانی چندمعماری

    با پارامترهای os و arch نسخه‌ی پلتفرم دلخواه را بگیرید (پیش‌فرض linux/amd64).

  • قابل ادامه (Resume)

    دانلودهای نیمه‌تمام با wget -c از همان‌جا ادامه می‌شوند — مناسب خطوط کند و ناپایدار.

  • سبک و کم‌نیاز

    با حداقل منابع و بدون وابستگی‌های سنگین اجرا می‌شود؛ راه‌اندازی کامل با یک دستور و بدون تنظیمات پیچیده.

شروع سریع

در کمتر از یک دقیقه بالا می‌آید.

راه‌اندازی (Self-host) 
git clone https://github.com/sadra824/internal-docker-registry.git
cd internal-docker-registry
npm install
npm start             # روی پورت :5000 بالا می‌آید

# دریافت هر ایمیج عمومی از طریق رجیستری:
docker pull localhost:5000/library/nginx:latest
دریافت ایمیج 
# مستقیم داخل داکر:
wget -q -O - "https://registry.sadhanet.com/image?name=nginx:latest" | docker load

# یا دانلود با قابلیت ادامه:
wget -c --content-disposition "https://registry.sadhanet.com/image?name=nginx:latest"
docker load -i nginx_latest.tar
معماری و پلتفرم دلخواه 
# دانلود نسخه‌ی arm64 (پیش‌فرض linux/amd64):
wget -q -O - "https://registry.sadhanet.com/image?name=nginx:latest&os=linux&arch=arm64" | docker load

# فهرست پلتفرم‌های موجود یک ایمیج:
curl "https://registry.sadhanet.com/platforms?name=nginx:latest"

سپس http://localhost:5000 را باز کنید — همین صفحه توسط خودِ سرویس سرو می‌شود.

دستورهای API

سبک و ساده — همه چیز با یک GET.

دستور کاربرد
GET /image?name=<ref> دانلود مستقیم تاربال ایمیج — استریم pass-through با پشتیبانی resume
GET /image?name=<ref>&os=<os>&arch=<arch> انتخاب پلتفرم (پیش‌فرض linux/amd64)
GET /platforms?name=<ref> فهرست پلتفرم‌های موجود ایمیج
Range: bytes=… ادامه‌ی دانلود نیمه‌تمام (wget -c)
/v2/… API سازگار با Registry v2 نیز موجود است (برای ایمیج‌های بزرگ به CPU بیشتر نیاز دارد)
